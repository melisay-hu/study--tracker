# AI Study Assistant

An intelligent study tracking application built with Python.

## Features

- Track study sessions by subject
- Store study history automatically
- Generate study summaries
- AI-powered study recommendations
- Visual progress charts
- Persistent data storage using JSON

## Technologies Used

- Python
- JSON
- Git
- GitHub

## Example Use Case

A student records their study sessions:

- Database Systems → 2 hours
- IoT → 1 hour
- Optimization → 4 hours

The application analyzes study history and suggests which subject should receive more attention.
